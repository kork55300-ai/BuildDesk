# BuildDesk v1 — незалежний прототип

Це окремий проєкт, не пов'язаний із застосунком «Откоси».

## Запуск
Завантажте файли в окремий GitHub-репозиторій і ввімкніть GitHub Pages (Settings → Pages → Deploy from branch → main → root). Відкрийте HTTPS-посилання на Android і виберіть «Додати на головний екран».

## Реалізовано
- Темний адаптивний інтерфейс і нижня навігація.
- Налаштовувані блоки головного екрана.
- Створення замовлень та об'єктів.
- Додавання робіт з кількістю, одиницею та ціною.
- Автоматичний підрахунок вартості.
- Журнал надходжень і витрат.
- Локальне збереження в браузері.
- Експорт та імпорт JSON-резервної копії.
- PWA manifest і кешування оболонки для офлайн-відкриття.

## Що ще не реалізовано
Сервер, облікові записи, синхронізація між пристроями, розмежування ролей, повноцінний каталог/конструктор формул, склад, команда, документи, вкладення, розширена аналітика. Це наступні етапи. Поки дані локальні — регулярно експортуйте резервну копію та не зберігайте єдину копію важливої інформації.
