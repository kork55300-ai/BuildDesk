# BuildDesk v2 — оновлений незалежний прототип

Окремий будівельний застосунок, не пов'язаний із Otkosy.

## Розгортання
Завантажте вміст папки `BuildDesk-v1` у корінь окремого GitHub-репозиторію (або весь архів із папкою), увімкніть GitHub Pages: Settings → Pages → Deploy from branch → main → root.

## Реалізовано у v2
- Темний адаптивний інтерфейс, оптимізований для Android.
- Замовлення: створення, редагування, статуси та видалення з підтвердженням.
- Об'єкти в межах замовлення: створення, редагування, видалення разом із вкладеними виробами та роботами.
- Вироби об'єкта: окремі вікна й двері з номером, шириною, висотою, кількістю, профілем, типом відкривання, кольором, ціною та приміткою.
- Редагування та видалення окремих вікон/дверей.
- Роботи на об'єкті з кількістю, одиницею та ціною.
- Автоматичний підрахунок вартості робіт і виробів у замовленні.
- Фінансові операції з прив'язкою до замовлення, видалення операцій.
- Базові довідники клієнтів, каталогу робіт і матеріалів (додавання/видалення назв).
- Налаштування блоків головного екрана.
- Експорт і відновлення JSON-резервної копії.
- Локальне збереження даних, PWA та офлайн-кеш оболонки.

## Обмеження поточної версії
- Дані зберігаються локально в браузері на одному пристрої; серверної синхронізації та облікових записів немає.
- Модулі команди, документів, повноцінного складу матеріалів, аналітики та прикріплення фотографій ще потребують реалізації.
- Каталог і матеріали наразі є простими довідниками, ще не підключеними до автоматичного розрахунку робіт.
- Перед очищенням даних браузера експортуйте резервну копію.
